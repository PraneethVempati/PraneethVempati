## 🔬 Featured: Hallucination Detection in Text-to-Image Generation

> *Most hallucination detection methods require model access or fine-tuning. This works on any diffusion model, out of the box.*

[![Live Demo](https://img.shields.io/badge/🚀_Live_Demo-HuggingFace_Spaces-FFD21E?style=for-the-badge)](https://huggingface.co/spaces/walter11white/Hallucination-Detection-Faithfulness-Checker)

| What | How |
|---|---|
| **Approach** | Training-free, model-agnostic evaluation pipeline |
| **Models tested** | Stable Diffusion v1.5 · SDXL-Turbo |
| **Scoring** | VQA-based faithfulness scoring (BLIP-VQA) |
| **Validation** | POPE benchmark · ROC-AUC measurement |
| **Uncertainty signal** | Faithfulness variance across N images per prompt |
| **Deployment** | 5-tab Gradio app · POPE, OK-VQA, Flickr30k benchmarking |
